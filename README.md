# 🔖 Smart Manual Helper

> **스마트 가전·디지털 매뉴얼 도우미**
> 가전제품 및 IT/디지털 기기 사용설명서(PDF) 기반 Q&A 대화형 RAG 챗봇

두껍고 복잡한 제품 설명서를 직접 뒤질 필요 없이, 자연어로 질문하면 **설명서 내용에 근거한 답변**과 **참고 페이지 출처**를 함께 알려주는 챗봇입니다. 노트북, 포터블 모니터, 게임패드, 키보드, 라즈베리파이 케이스 등 6종 기기의 설명서를 통합 검색합니다.

### 배경 및 필요성

복잡하고 두꺼운 제품 설명서는 필요할 때 원하는 내용을 찾기 어렵고, 에러 발생 시 조치법이나 세부 기능 연결 방법을 즉각 확인하기 힘듭니다. 이 프로젝트는 멀티 디바이스의 연결과 설정에 대해 자연어로 질의응답하고, 정확한 참고 페이지 출처를 함께 제공하여 사용자 편의성을 높이는 것을 목표로 합니다.

---

## 🎯 해결하려는 문제

1. **설명서 탐색의 어려움** — 연결 단자 사양, 단축키, 모드 전환 방법, 오류 해결법이 긴 매뉴얼 곳곳에 흩어져 있어 찾는 데 시간이 걸립니다.
2. **환각(Hallucination) 위험** — 일반 AI는 제품 스펙이나 단축키를 잘못 안내하여 기기 설정에 혼선을 줄 수 있습니다.
3. **출처 확인 필요** — 답변의 근거(페이지 번호)가 없으면 사용자가 답변의 신뢰성을 판단하기 어렵습니다.

## ✨ 주요 기능

- **설명서 기반 질의응답** — 질문과 관련된 설명서 내용을 검색해 답변을 생성합니다.
- **출처 제공** — 답변마다 근거가 된 문서명과 페이지(또는 섹션)를 함께 표시합니다.
- **환각 최소화** — 검색된 문서 내용에 근거해서만 답변하고, 설명서에 없는 내용은 없다고 안내합니다.
- **기기 필터링** — 질문에서 기기를 파악해 해당 설명서 위주로 검색하여, 비슷한 단축키나 연결 방법이 다른 기기와 섞이지 않도록 합니다.
- **한·영 교차 검색** — 영어 설명서(Z18S, Argon ONE)도 한국어 질문으로 검색하고 한국어로 답변합니다.

### 동작 흐름

```
[PDF 설명서] → 텍스트 추출 / OCR → 청크 분할 (+ 기기·페이지 메타데이터) → 임베딩 → 벡터 DB
                                                                              │
[사용자 질문] → 기기 판별 → 임베딩 → 유사 청크 검색 ─────────────────────────┘
                                         │
                                         ▼
                         LLM 답변 생성 + 출처(문서명·페이지) 표시
```

## 🔍 문서 데이터 특성과 전처리 전략

설명서마다 형식이 크게 달라서, 일괄적인 텍스트 추출만으로는 검색 품질을 확보하기 어렵습니다.

| 문서 | 텍스트 레이어 | 특이사항 | 전처리 방향 |
| --- | --- | --- | --- |
| LG 15UD50T | 있음 | 2단 레이아웃, 핫키·사양 표 다수 | 레이아웃 보존 추출, 표 단위 청크 |
| EX DUO | 있음 | 펼침면 구성, 일부 페이지 텍스트 중복 | 중복 제거, 번호 항목(1~28) 단위 청크 |
| Z18S | 거의 없음 | 페이지 전체가 이미지 | OCR 또는 비전 모델로 추출 |
| Argon ONE V2 | 일부 | 조립 단계가 그림 위주 | 표·문장은 추출, 그림 단계는 OCR/캡션 보완 |
| AK74 PRO | 없음 | 매우 긴 세로형 1페이지 이미지 | 구간을 잘라 OCR, 섹션 번호로 출처 표기 |
| AK27 OSCAFE | 없음 | 가로형 1페이지 이미지 | 구간을 잘라 OCR, 섹션 번호로 출처 표기 |

추가로 고려할 점은 다음과 같습니다.

- **페이지 번호 기준 통일** — LG 설명서는 표지가 있어 인쇄된 쪽 번호와 PDF 페이지 번호가 다르고, 키보드 설명서는 PDF가 1페이지뿐이라 페이지 번호가 출처로서 의미가 없습니다. 출처는 "인쇄 쪽 번호 또는 섹션명"으로 표기하는 규칙을 정해 두는 것이 좋습니다.
- **기기 간 혼동 방지** — AK27과 AK74 PRO는 같은 제조사 제품이라 FN 기능키 표 구조가 비슷하지만 키 배정이 다릅니다. 청크마다 기기명 메타데이터를 붙이고 검색 시 필터링해야 합니다.
- **설명서 자체의 오류** — 예를 들어 EX DUO 19항의 다이렉트인풋 연결 설명은 "15번 나항"을 참조하지만 실제로는 19항 ①-나)를 가리키는 것으로 보입니다. 이런 부분은 평가 시 챗봇이 원문을 그대로 옮기는지, 맥락에 맞게 안내하는지 확인하는 케이스로 활용할 수 있습니다.

## 🚀 시작하기

### 1. 저장소 클론

```bash
git clone https://github.com/<your-org>/<repo-name>.git
cd <repo-name>
```

### 2. 패키지 설치

```bash
pip install -r requirements.txt
# poetry 사용 시
poetry run pip install -r requirements.txt
```

### 3. 환경 변수 설정

프로젝트 루트에 `.env` 파일을 만들고 API 키를 입력합니다.

```env
OPENAI_API_KEY=your_api_key_here
```

### 4. 설명서 PDF 준비

`data/` 폴더에 위 6개 PDF를 넣습니다.

### 5. 실행

```bash
python app.py
```

실행 후 터미널에 표시되는 주소(기본값 `http://127.0.0.1:7860`)로 접속하면 챗봇을 사용할 수 있습니다.

> ⚠️ 위 명령어와 파일명은 예시입니다. 실제 레포 구조에 맞게 수정해 주세요.

## 📊 평가

- 기기별 실제 사용 시나리오를 바탕으로 **평가 질문셋**을 작성합니다. ([질문 예시](#-질문-예시) 참고)
